# Spesifikasi Teknis & Infrastruktur

- **Frontend Framework**: Flutter (Dart).
- **Backend & Database**: Supabase (PostgreSQL, Auth, Row Level Security).
- **Data API (Metadata) & Audio**: YouTube Music via package `youtube_explode_dart`.
- **Local Storage/Database**: Isar Database atau Hive (untuk cache metadata dan sistem offline).
- **State Management**: Riverpod, Bloc, atau Provider (pilih sesuai kenyamanan).
